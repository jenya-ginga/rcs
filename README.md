# Арифметика, 4 класс — тренажёр (уроки 13–31)

Сайт целиком статический: никаких серверных программ и баз данных. Оценки хранятся в браузере ребёнка.
Все тексты и задания написаны заново; числа в заданиях генерируются случайно.

## Открыть у себя
Дважды щёлкните по `index.html`. Работает и без интернета (без интернета вместо красивых шрифтов будут системные).

## Разместить бесплатно (любой из вариантов)
- **Netlify**: зайти на app.netlify.com/drop и перетащить всю папку.
- **Cloudflare Pages**: Workers & Pages → Create → Pages → Upload assets, загрузить папку.
- **GitHub Pages**: создать репозиторий, загрузить файлы, Settings → Pages → Deploy from a branch → main / root.

## Как устроено
- `js/course.js` — карта курса: 200 уроков и разделы (названия уроков задаются в файлах с уроками).
- `js/lessons-numeration.js` — содержание уроков 13–20: теория, наборы заданий.
- `js/lessons-addsub.js` — содержание уроков 21–31 (сложение и вычитание больших чисел, проверочная, работа над ошибками).
- `js/gens-addsub.js` — генераторы заданий для уроков 21–31 и запись примеров столбиком.
- `js/gens.js` — генераторы заданий (числа каждый раз новые).
- `js/widgets.js` — таблица разрядов, счёты, конвертеры.
- `js/app.js`, `css/style.css` — интерфейс.
- `js/consent.js` — плашка о cookie; счётчик Яндекс.Метрики (113133874) загружается только после «Принять».
- `privacy/index.html` — политика конфиденциальности (`/privacy/`).

## Как добавить урок
В новом файле `js/lessons-….js` (подключить в `index.html` перед `app.js`) добавить
`RKS.LESSONS[номер] = { title, goal, theory: [{h, html}], oral: [...], practice: [...], problems: [...] }`.
Наборы описываются как `{ g: 'имя генератора', n: сколько, o: { параметры } }`.
Новые типы заданий добавляются в `js/gens.js` как `gens.имя = function (o) { return { kind, html, answer, hint, explain }; }`.
