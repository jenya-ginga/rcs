# Арифметика, 4 класс — тренажёр

Сайт целиком статический: никаких серверных программ и баз данных. Оценки хранятся в браузере ребёнка.
Все тексты и задания написаны заново; числа в заданиях генерируются случайно.
Курс — 200 уроков; на карте курса кликабельны те уроки, которые уже написаны.

## Открыть у себя
Для просмотра нужен любой простой веб-сервер (например, `python3 -m http.server` в папке сайта) — страницы ссылаются друг на друга по адресам вида `/o-nas/`. Шрифты лежат в папке `fonts`, с внешних серверов ничего не подгружается (Яндекс.Метрика — только после «Принять»).

## Разместить бесплатно (любой из вариантов)
Важно: Vercel и Netlify из РФ часто не открываются без VPN. Для российских посетителей нужна копия на российском хостинге — папка `ru` (весь сайт целиком, пути относительные; собирается из этих же файлов).

- **Vercel** (текущий вариант): репозиторий на GitHub подключён к Vercel, каждый push публикуется сам.
- **Netlify**: зайти на app.netlify.com/drop и перетащить всю папку.
- **Cloudflare Pages**: Workers & Pages → Create → Pages → Upload assets, загрузить папку.
- **GitHub Pages**: Settings → Pages → Deploy from a branch → main / root.

## Как устроено
- `js/course.js` — карта курса: 200 уроков, разделы и виды работ (проверочные, самостоятельные, работа над ошибками).
- `js/lessons-*.js` — содержание уроков: теория, наборы заданий. Один файл на раздел курса.
- `js/gens*.js` — генераторы заданий (числа каждый раз новые); `js/gens-*.js` — по разделам курса.
- `js/render-md.js` — запись примеров столбиком и уголком, пошаговые пояснения к ним.
- `js/widgets.js` — таблица разрядов, счёты, конвертеры.
- `js/app.js`, `css/style.css` — интерфейс; `css/fonts.css` и `fonts/` — шрифты PT Serif и Marck Script (лицензия SIL OFL).
- `js/consent.js` — плашка о cookie; счётчик Яндекс.Метрики (113133874) загружается только после «Принять».
- `build/build-site.js` и `build/pages/*.html` — генератор каркаса: шапка с меню, хлебные крошки, подвал, главная, «Школа», «О нас», «Методология», заглушки «Доп. материалы», «Блог», политика, 404, `sitemap.xml`, `robots.txt`. Запуск: `node build/build-site.js` (после каждого нового урока — на главной указано число открытых уроков). `--check` ничего не пишет и сообщает, устарели ли страницы.
- `css/site.css`, `js/site.js` — оформление и поведение шапки, меню и подвала.
- `shkola/nachalnaya/4-klass/index.html` — страница тренажёра (пишется вручную; генератор заменяет в ней только участки `<!--site:head-->`, `<!--site:header-->`, `<!--site:footer-->`).
- `vercel.json` — адреса со слэшем на конце (`/o-nas/`).

## Как добавить урок
В новом файле `js/lessons-….js` (подключить в `shkola/nachalnaya/4-klass/index.html` перед `app.js`, путь `../../../js/…`; затем запустить `node build/build-site.js`) добавить
`RKS.LESSONS[номер] = { title, goal, theory: [{h, html}], oral: [...], practice: [...], problems: [...] }`.
У проверочной работы вместо трёх наборов — `test: true` и `testSpec: [...]`.
Наборы описываются как `{ g: 'имя генератора', n: сколько, o: { параметры } }`.
Новые типы заданий добавляются в `js/gens-….js` как `gens.имя = function (o) { return { kind, html, answer, hint, explain }; }`.
